# Decisions and research

## Start with a local web viewer

A Vite static build allows a local first milestone and a future Cloudflare Pages Git integration. React, TypeScript, Three.js and React Three Fiber provide typed scene and UI boundaries. Installation and offline behavior are later deliverables. The current app persists theme and highlight color through local storage and has no backend or analytics. [Vite](https://vite.dev/guide/) · [Cloudflare Git integration](https://developers.cloudflare.com/pages/configuration/git-integration/) · [MDN PWA documentation](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps)

## Pin the optimized Écorché asset

The upstream model has 634 named structures. Its world-space orientation is Y up, with the anterior surface facing +Z. The prototype parses the 5.7 MiB meshopt GLB using Three.js and checks exact selectors against the decoded scene. The manifest, GLB hashes, and attribution travel with the checkout. The model is an adult male static figure. The prototype uses two source-labeled left-side structures to exercise grouping and target replacement. [Pinned Écorché source](https://github.com/Charleeh/ecorche/tree/320805e06aee51e2e6f6b22533eb2a59d43f2d4d) · [GLTFLoader documentation](https://threejs.org/docs/#GLTFLoader)

## Keep transcription, matching and review distinct

Figures 6.22 and 6.23 fix the curriculum. The scope file is imported verbatim. The viewer resolves exact name, layer, side, source and optional group on actual meshes. Phase 2 must establish a separate audit and human approval record before any structure is scored. Terminologia Anatomica and OpenStax support nomenclature and independent descriptive checks. Neither reference certifies a particular model surface. [IFAA terminology](https://ifaa.net/committees/anatomical-terminology-fipat/fipat-ifaa-terminologies/) · [OpenStax head, neck and back muscles](https://openstax.org/books/anatomy-and-physiology-2e/pages/11-3-axial-muscles-of-the-head-neck-and-back)
