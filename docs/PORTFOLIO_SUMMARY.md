# Portfolio summary · In progress

Anatomy Quiz is an in-development web app for learning human anatomy through interactive 3D identification. Its curriculum is bounded by 46 named targets from two textbook figures. The technical challenge is selecting exact, licensed model surfaces and making the selected structure legible across regions and depths.

The student supplied the curriculum, the requirements for a restrained red/blue Focus view, the staged portfolio plan, and the constraints for public release. Codex implemented the local scaffold, the first viewer slice, automated checks, and this documentation. The development log records what was completed. Future entries should record the student's actual review, design decisions, and code contributions as they happen.
